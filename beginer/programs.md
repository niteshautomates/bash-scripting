# Bash Scripting Practice Programs

This repository contains a collection of basic to intermediate Bash scripts designed to strengthen your understanding of syntax, loops, conditionals, and file operations in shell scripting.

## 🧰 Topics Covered

- Basic Syntax
- Conditional Statements (`if`, `case`)
- Loops (`for`, `while`, `until`)
- File and Directory Operations
- System Information and User Management
